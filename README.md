# Скидки для своих — проверенные скидки на одежду, обувь и аксессуары

Приложение для телефона: Android (APK) и iPhone (веб-приложение на экране «Домой»). Каждое утро само собирает скидки
в 25 интернет-магазинах Украины, проверяет, что скидка **настоящая**, и показывает их по категориям с фильтрами
под каждого пользователя.

## Что умеет

- **Первый запуск**: пользователь выбирает, для кого ищет скидки (женское, мужское, для дочери, для сына), размеры
  и что интересует больше всего. Регистрации нет — всё хранится на телефоне.
- **Профили**: можно добавить профили для всей семьи. У каждого свои размеры одежды и обуви, для кого (женское, мужское,
  девочки, мальчики), интересные категории, любимые и скрытые бренды, минимальная скидка, предел цены и магазины.
  Телефон скачивает только нужные профилям части данных (женское / мужское / детское).
- **Сортировка**: каждая категория открывается с самых больших *реальных* скидок; можно переключить на
  «Лучшее для меня», «Сначала дешёвые», «Сначала новые».
- **Категории**: одежда (верхняя, платья и юбки, свитера и худи, брюки и джинсы…), обувь, сумки, аксессуары.
- **Проверка скидок**: приложение каждый день запоминает цену каждого товара и считает скидку не от «старой цены»
  магазина, а от цены, по которой товар реально продавался. Значки на карточках:
  - ✓ проверено — товар действительно продавался по старой цене;
  - мин. цена за 60 дн, подешевело сегодня, новое;
  - завышенная старая цена, уже было дешевле, давно по этой цене — такие скидки опускаются вниз или скрываются;
  - неправдоподобная скидка — на маркетплейсах (Kasta, Rozetka, Prom) заявлено −85% и больше без подтверждения.
- **Сортировка «Лучшее для меня»** учитывает реальную скидку, любимые бренды и подходящий размер.
- **«Больше всего интересует»** в профиле — выбранные вещи (платья, кроссовки, сумки…) идут первыми
  в «Лучшее для меня» и в уведомлении.
- **Уведомление каждое утро**: 20 самых горящих скидок для профиля, выбранного на этом телефоне
  в **Настройки → Уведомления**, по тем же фильтрам, что в приложении; уже присланные товары не повторяются,
  пока не подешевеют. Нажатие открывает экран «Горящие».
  - Android-приложение отбирает и показывает уведомление само, около 9:00.
  - iPhone (iOS 16.4+, с иконки на экране «Домой») и браузеры: подписку хранит сервер на Cloudflare, рассылает
    GitHub Actions — см. «Уведомления для iPhone и браузеров».
- **Избранное** — сердечко на карточке; если цена изменится, будет видно «было / стало».
- Кнопка **«Открыть в магазине»** ведёт прямо на страницу товара, где можно оформить заказ.

Настройки и избранное хранятся на телефоне. Если на iPhone или в браузере включены уведомления, на сервер подписок
уходят только адрес подписки браузера и фильтры выбранного профиля (размеры, бренды, скидка) — без имён и контактов,
кроме имени профиля для заголовка уведомления.

Как добавить магазин: если карточки товаров приходят готовым HTML — описать их настройками `Shop`
в `scraper/stores/shops.py` (регулярные выражения для названия, цены, старой цены…); иначе написать модуль
в `scraper/stores/` с функцией `scrape(http)`, которая отдаёт `Item`, и вписать его в `scraper/stores/__init__.py`.

Сборщик соблюдает robots.txt каждого сайта (включая шаблоны `*` и паузу `Crawl-delay`) и делает паузу
1,5–3 секунды между запросами к одному сайту.

## Как запустить в интернете (бесплатно, через GitHub)

1. Зарегистрируйтесь на <https://github.com>.
2. Создайте репозиторий: кнопка **New** → имя `skidki` → **Public** → **Create repository**
   (README не добавляйте).
3. В PowerShell в папке проекта:
   ```powershell
   git remote add origin https://github.com/ВАШ_ЛОГИН/skidki.git
   git push -u origin main
   ```
   Откроется окно входа в GitHub — войдите.
4. В репозитории на GitHub: **Settings → Pages → Source: GitHub Actions**.
5. **Actions → «Ежедневный сбор скидок» → Run workflow**. Через 10–15 минут приложение будет доступно по адресу
   `https://ВАШ_ЛОГИН.github.io/skidki/`.
6. Дальше всё работает само: каждую ночь в 03:17 по Киеву (запасной запуск в 05:17 — GitHub иногда опаздывает
   с расписанием на несколько часов; если скидки уже собраны, запасной ничего не делает).

### Уведомления для iPhone и браузеров

Android-приложение присылает уведомления само. Для iPhone и браузеров нужен маленький бесплатный сервер подписок
на Cloudflare (`worker/index.js`) и ключ уведомлений. Один раз:

1. Ключ уведомлений: создайте 32 случайных байта в base64url (например,
   `python -c "import os,base64;print(base64.urlsafe_b64encode(os.urandom(32)).decode().rstrip('='))"`)
   и сохраните копию вне репозитория. Если ключ сменить, все подписки придётся включать заново.
2. Зарегистрируйтесь на <https://dash.cloudflare.com> (бесплатно).
3. **My Profile → API Tokens → Create Token → шаблон «Edit Cloudflare Workers»** → Account Resources: ваш аккаунт,
   Zone Resources: All zones → **Create Token** → скопируйте токен.
4. ID аккаунта: на главной панели Cloudflare справа, **Account ID**.
5. В репозитории на GitHub: **Settings → Secrets and variables → Actions → New repository secret** — три секрета:
   `VAPID_PRIVATE_KEY` (ключ из п. 1), `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`.
6. **Actions → «Сервер уведомлений» → Run workflow**. Он создаст хранилище подписок, опубликует сервер
   и переопубликует сайт с его адресом.

Рассылка — workflow «Уведомления в браузере и на iPhone»: раз в час с 8:07 до 15:07 по Киеву, каждому подписчику
не чаще раза в день, как только готовы сегодняшние скидки. На бесплатном тарифе Cloudflare хватает примерно
на 800 подписчиков (1000 записей в хранилище в день).

### Android-приложение

Приглашение для семьи — ссылка `https://ВАШ_ЛОГИН.github.io/skidki/install.html`: на ней кнопка «Скачать»
и пошаговая инструкция по установке APK.

- Код приложения — в `android/` (оболочка на WebView: показывает сайт, ссылки на магазины открывает в браузере
  или в приложении магазина). Скидки и интерфейс обновляются сами, переустанавливать APK не нужно.
- APK собирается в GitHub Actions (workflow «Android-приложение») при изменениях в `android/` и выкладывается
  в Releases как `skidki.apk`.
- Подпись: ключ `skidki.p12` хранится в секретах репозитория `KEYSTORE_B64` / `KEYSTORE_PASSWORD` и в локальной папке
  `skidki-keys` рядом с проектом. Без него новые версии не установятся поверх старых — храните копию.

Можно и без APK: открыть сайт в Chrome → меню **⋮** → **«Добавить на главный экран»**.

## Запуск на компьютере (для проверки и доработки)

```powershell
pip install -r requirements.txt
python -m scraper.main                 # собрать скидки во всех магазинах (~3 минуты)
python -m scraper.main --only sinsay   # один магазин
python -m tests.test_logic             # проверки логики
python -m http.server 8000 --directory app   # открыть http://localhost:8000
```

## Устройство

```
scraper/            сбор данных (Python)
  stores/           по модулю на магазин
  classify.py       категория и «для кого» по названию товара
  history.py        история цен (только точки изменения цены)
  scoring.py        проверка, настоящая ли скидка, и оценка
  main.py           запуск всех магазинов → app/data/deals.json + meta.json и части w/m/k.json
  push.py           уведомления в браузере и на iPhone (отбор и рассылка)
app/                приложение (PWA: HTML + JS, без сборки)
android/            Android-приложение (оболочка + ежедневное уведомление)
worker/             сервер подписок на уведомления (Cloudflare Workers)
.github/workflows/  ежедневный сбор и публикация, рассылка, сервер уведомлений, сборка APK
```

История цен и свежие скидки хранятся в отдельной ветке `data` — она перезаписывается каждый день,
поэтому репозиторий не растёт.

## Ограничения

- Сбор идёт с публичных страниц магазинов. Если магазин поменяет сайт, его сборщик перестанет работать —
  в **Настройках → Магазины** будет видно «не ответил», а в приложении останутся его последние данные.
- Проверка «завышенной старой цены» начинает работать примерно через неделю после первого запуска,
  когда накопится история (кроме LC Waikiki — там с первого дня).
- Сайты с защитой от ботов не подключены: Answear, Intertop (и Ecco — он ведёт на Intertop), MD Fashion, Decathlon,
  Arber, Next, Rozetka (закрыта для серверов GitHub), H&M.
- Не подключены сайты, которые строят каталог скриптом в браузере (в самой странице товаров нет): Zara, Massimo Dutti,
  Pull&Bear, Bershka, Stradivarius, Oysho, Mango, Shafa, Shopping.ua, Sport City, Columbia, Invogue, Shift,
  Helen Marlen, Leboutique. Modivo и eobuv хранят цены в сжатом скрипте страницы.
- MustHave не показывает в каталоге старую цену, The Icon — картинки только в формате JPEG 2000 (не видны в Android).
- Не нашлись по адресам из списка: walker.ua, geox.ua, skechers.ua, underarmour.ua.
