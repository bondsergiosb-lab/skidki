# Скидки — проверенные скидки на одежду, обувь и аксессуары

Приложение для телефона (Android). Каждое утро само собирает скидки в интернет-магазинах Украины,
проверяет, что скидка **настоящая**, и показывает их по категориям с фильтрами под каждого члена семьи.

## Что умеет

- **Профили**: «Мама», «Старшая», «Младшие». Можно переименовать, удалить и добавить свои. У каждого профиля свои
  размеры одежды и обуви, интересные категории, любимые и скрытые бренды, минимальная скидка, предел цены и магазины.
- **Категории**: одежда (верхняя, платья и юбки, свитера и худи, брюки и джинсы…), обувь, сумки, аксессуары.
- **Проверка скидок**: приложение каждый день запоминает цену каждого товара и считает скидку не от «старой цены»
  магазина, а от цены, по которой товар реально продавался. Значки на карточках:
  - ✓ проверено — товар действительно продавался по старой цене;
  - мин. цена за 60 дн, подешевело сегодня, новое;
  - завышенная старая цена, уже было дешевле, давно по этой цене — такие скидки опускаются вниз или скрываются.
- **Сортировка «Лучшее для меня»** учитывает реальную скидку, любимые бренды и подходящий размер.
- **Избранное** — сердечко на карточке; если цена изменится, будет видно «было / стало».
- Кнопка **«Открыть в магазине»** ведёт прямо на страницу товара, где можно оформить заказ.

Настройки и избранное хранятся только на телефоне.

## Магазины

| Магазин | Что берём | Особенности |
|---|---|---|
| Megasport | аутлет: женское и для девочек | Nike, Adidas, Puma, New Balance, Jordan и др.; размеры в наличии |
| Sinsay | распродажа: женское и детское | размеры в наличии; пол у детских вещей определяется по названию |
| LC Waikiki | акции: женское | магазин сам публикует минимальную цену за месяц — по ней скидка подтверждается с первого дня |

Как добавить магазин: написать модуль в `scraper/stores/` с функцией `scrape(http)`, которая отдаёт `Item`,
и вписать его в `scraper/stores/__init__.py`. Для Reserved, Cropp, House и Mohito (платформа LPP) уже есть общий парсер
`scraper/stores/lpp.py` — нужно только проверить адреса разделов распродажи.

## Как запустить в интернете (бесплатно, через GitHub)

1. Зарегистрируйтесь на <https://github.com>.
2. Создайте репозиторий: кнопка **New** → имя `skidki` → **Public** → **Create repository**
   (README не добавляйте).
3. В PowerShell в папке проекта:
   ```powershell
   git remote add origin https://github.com/ВАШ_ЛОГИН/skidki.git
   git push -u origin main
   ```
   Откроется окно входа в GitHub — войдите.
4. В репозитории на GitHub: **Settings → Pages → Source: GitHub Actions**.
5. **Actions → «Ежедневный сбор скидок» → Run workflow**. Через 5–10 минут приложение будет доступно по адресу
   `https://ВАШ_ЛОГИН.github.io/skidki/`.
6. Дальше всё работает само: каждый день в 06:00 (зимой; летом в 07:00) по Киеву.

### Android-приложение

Приглашение для семьи — ссылка `https://ВАШ_ЛОГИН.github.io/skidki/install.html`: на ней кнопка «Скачать»
и пошаговая инструкция по установке APK.

- Код приложения — в `android/` (оболочка на WebView: показывает сайт, ссылки на магазины открывает в браузере
  или в приложении магазина). Скидки и интерфейс обновляются сами, переустанавливать APK не нужно.
- APK собирается в GitHub Actions (workflow «Android-приложение») при изменениях в `android/` и выкладывается
  в Releases как `skidki.apk`.
- Подпись: ключ `skidki.p12` хранится в секретах репозитория `KEYSTORE_B64` / `KEYSTORE_PASSWORD` и в локальной папке
  `skidki-keys` рядом с проектом. Без него новые версии не установятся поверх старых — храните копию.

Можно и без APK: открыть сайт в Chrome → меню **⋮** → **«Добавить на главный экран»**.

## Запуск на компьютере (для проверки и доработки)

```powershell
pip install -r requirements.txt
python -m scraper.main                 # собрать скидки во всех магазинах (~3 минуты)
python -m scraper.main --only sinsay   # один магазин
python -m tests.test_logic             # проверки логики
python -m http.server 8000 --directory app   # открыть http://localhost:8000
```

## Устройство

```
scraper/            сбор данных (Python)
  stores/           по модулю на магазин
  classify.py       категория и «для кого» по названию товара
  history.py        история цен (только точки изменения цены)
  scoring.py        проверка, настоящая ли скидка, и оценка
  main.py           запуск всех магазинов → app/data/deals.json
app/                приложение (PWA: HTML + JS, без сборки)
.github/workflows/  ежедневный запуск и публикация
```

История цен и свежие скидки хранятся в отдельной ветке `data` — она перезаписывается каждый день,
поэтому репозиторий не растёт.

## Ограничения

- Сбор идёт с публичных страниц магазинов. Если магазин поменяет сайт, его сборщик перестанет работать —
  в **Настройках → Магазины** будет видно «не ответил», а в приложении останутся его последние данные.
- Проверка «завышенной старой цены» начинает работать примерно через неделю после первого запуска,
  когда накопится история (кроме LC Waikiki — там с первого дня).
- Сайты с защитой от ботов (Answear, Intertop, MD-Fashion, H&M) пока не подключены.
