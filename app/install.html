Скачать приложение для Android

Файл около 1 МБ. Приложение бесплатное, без рекламы и регистрации.

Как установить

  1. Нажмите «Скачать приложение». Если Chrome предупредит, что файл может быть опасен, нажмите «Всё равно скачать».
  2. Откройте скачанный файл skidki.apk (из уведомления или из папки «Загрузки»).
  3. Телефон попросит разрешить установку из этого источника — нажмите «Настройки», включите «Разрешить из этого источника» и вернитесь назад.
  4. Нажмите «Установить». Если появится окно Google Play Защиты — выберите «Подробнее» → «Всё равно установить». Предупреждение появляется потому, что приложение не из Play Маркета.
  5. Готово — на экране появится иконка «Скидки».

Обновлять приложение не нужно: скидки и новые функции подгружаются сами.
